Reinforcement learning · DJI Tello · UTS 42028

A drone that flies through a hoop, loops round, and goes through again

A Tello sees a 30 cm foam hoop only through its own front camera. With 8 cm of room on each side, it has to find the hoop, line up, go through, fly round the outside, find it again and re-enter, as many times as it can in 90 seconds. Every policy here was trained in our simulator with reinforcement learning, and the best ones were flown on the real drone.

The best policy, flying

A recording from the simulator (the same physics, camera model and randomisation the policy was trained on). Drag to rotate, scroll to zoom. The hoop turns green on a pass, and it swings, as the real one does.

How it works

The policy sees only what the Tello's camera sees: a hoop tracker turns each frame into a few numbers (where the ring is, how big, how sure), the last second of them is kept as memory, and a small neural network turns that into stick commands 15 times a second. It was trained with PPO in a simulator of our cage, drone and camera, with everything randomised so it survives the real thing.

Try it yourself

Training, the simulator and flying the drone run on your own computer: the trainer needs Python and the simulator, and the dashboard talks to the Tello over Wi-Fi. Download the project and this same dashboard opens locally with every button working.

Get the code on GitHub Hand-over notes
What works only on your own computer
  • Simulator › Train: starting, stopping and watching trainings; replays and the drone's-eye camera
  • Simulator › Environment: the phone scan of the real cage (34 MB)
  • Drone: flying (simulated or real), keyboard flight, camera calibration, recording demos
  • Drone › Demos & clones: making demos and training behaviour clones
Online, those controls carry a Local only tag.

1. Get the project

git clone https://github.com/MichelleGun/CMS.git
cd CMS

Then follow SETUP.md: a conda environment called drones (Python 3.12; CPU PyTorch is enough). Check it with python -m pytest hardware/onboard/tests -q.

2. Open the dashboard

conda activate drones
python -m uvicorn main:app --app-dir webapp/backend --port 8000

Then open http://localhost:8000: this same page, with every tab working.

3. Train a policy

Continue the best policy with one experiment (a run folder appears in results/hoop/runs/):

python hardware/onboard/loop_night.py --vec subproc --keys C9 --parent results/hoop/runs/w10_mg6_C9_loop_practice --tag yourname --timesteps 2000000 --n-envs 4 --parallel 1 --resume-crashed

The experiments are in hardware/onboard/week10_experiments.py; HANDOVER.md says what has been tried, what worked and what to try next. For the hierarchy: hardware/onboard/hrl_pipeline.py.

4. Fly it on a Tello

python hardware/onboard/export_policy.py results/hoop/runs/w10_yourname_C9_loop_practice
python hardware/onboard/fly_hoop.py --mode policy --model hardware/policies/<file>.zip --detector day

Calibrate the camera for the light first (Drone tab → Calibrate camera): daylight through a window can look like the hoop. Fly in a netted cage, with someone ready on the land / motor-cut keys.

Update these results

python scripts/build_site.py --record

It rewrites webapp/frontend/data/. Pushing that to GitHub republishes the online copy.

Training progress

All training is PPO (actor-critic) in our simulator of the real cage, drone and camera, with randomised dynamics so the policy survives the real drone. Each run continues from the previous milestone. Every run's own curves are under Run history; starting one is Simulator › Train.

Learning curves

Passes per 90 s episode at each evaluation (36 fixed episodes), against the steps that run added.

The loop optimiser

A script races the best policy so far against one new idea per round, re-scores both on the same 72 episodes plus 60 slanted starts (score = passes/episode + corner entry), and keeps a challenger only if it wins by more than 0.10. Rounds 1–8 were scored on one 36-episode evaluation with corners at half weight; from round 9 every candidate is re-scored on the same 72 + 60 episodes and corners count fully, so those scores are higher and steadier.

Hierarchical RL

Skills for each phase ("enter the hoop", "loop and find it again") and a manager that picks one every 0.53 s (the options framework), compared with the flat best policy and a fixed switch. How it works.

    The arena the policy trains in
    
        
    The simulated cage the policy trains in: a 2×2×2 m net with a blue
          noodle ring hung near the centre, posed like the one in the phone scan (1.29 m up, turned and
          leaning slightly). The drone always starts on the floor, must take off, find the ring and
          fly through it in the arrow's direction. Touching the net bounces it back.

          training). "Max swing" is how far it can swing; it is the same setting as in the Training panel.
