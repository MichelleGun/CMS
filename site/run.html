Run it yourself

This site only shows results. Training, the dashboard and flying the drone run on your own computer: the trainer needs Python and the simulator, and the dashboard talks to the drone over Wi-Fi.

1. Get the project

git clone https://github.com/MichelleGun/CMS.git
cd CMS

Then follow SETUP.md: a conda environment called drones (Python 3.12, CPU PyTorch is enough). Check it with python -m pytest hardware/onboard/tests -q.

2. Open the dashboard

conda activate drones
python -m uvicorn main:app --app-dir webapp/backend --port 8000

Then open http://localhost:8000. From there you can start and watch trainings, replay any run in 3D, calibrate the camera (day / night presets) and fly the drone.

3. Train a policy

Continue the best policy with one experiment (a run folder appears in results/hoop/runs/):

python hardware/onboard/loop_night.py --vec subproc --keys C9 --parent results/hoop/runs/w10_mg6_C9_loop_practice --tag yourname --timesteps 2000000 --n-envs 4 --parallel 1 --resume-crashed

The experiments are listed in hardware/onboard/week10_experiments.py; the hand-over notes (HANDOVER.md) say what has been tried, what worked, and what to try next. For the hierarchy: hardware/onboard/hrl_pipeline.py.

4. Fly it on a Tello

Score and package a policy (it lands in hardware/policies/, ranked in its README), then fly it:

python hardware/onboard/export_policy.py results/hoop/runs/w10_yourname_C9_loop_practice
python hardware/onboard/fly_hoop.py --mode policy --model hardware/policies/<file>.zip --detector day

Calibrate the camera for the light first (dashboard → Drone → Calibrate camera): daylight through a window can look like the hoop. Fly in a netted cage, with someone ready on the land / motor-cut keys.

Rebuild this site

python scripts/build_site.py --record
git add site && git commit -m "Site: new results" && git push

GitHub Actions publishes the site/ folder to GitHub Pages on every push that changes it.
